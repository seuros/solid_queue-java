# SolidQueue::Java

Java/JRuby support for [Solid Queue](https://github.com/rails/solid_queue).

## Installation

```bash
bundle add solid_queue-java
```

## Requirements

- JRuby 9.4+ or TruffleRuby 24.0+
- Rails 7.1+
- Solid Queue >= 1.2.0
